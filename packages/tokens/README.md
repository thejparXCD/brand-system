# @celebration-onpoint/tokens

Source of truth for Celebration OnPoint visual foundations.

Link `styles.css` to inherit color, type, spacing, effects, and Light Fields custom properties.

```html
<link rel="stylesheet" href="packages/tokens/styles.css">
```

Brand-specific token names (`--c-blue`, `--c-gold`, `--n-900`, `--grad-bolt`, …) live here. The Open Design import package at `open-design/celebration-onpoint/tokens.css` maps the same decisions onto the shared Open Design schema (`--bg`, `--fg`, `--accent`, …).
