# Open Design — 2 minutes

Use this folder in Open Design:

```text
design-systems\celebration-onpoint
```

Full path on your PC (after `git pull`):

```text
C:\Projects\Brand-System\brand-system-main\design-systems\celebration-onpoint
```

---

## Do this

### 1. Update the repo (once)

Double-click **`open-design-here.bat`** in this repo  
—or run in Command Prompt:

```bat
cd C:\Projects\Brand-System\brand-system-main
git pull
```

### 2. Open Design → “Design a system, in minutes”

1. Open **Advanced**
2. **Link local code** → **Browse folder**
3. Pick the folder **`celebration-onpoint`** inside **`design-systems`**
4. Click **Generate**

You do **not** need GitHub URL, Figma, or “Describe brand” unless you want them.

### 3. Optional — paste in **Notes**

```text
Celebration OnPoint. Blue #1056A5 foundation. Gold #F5C518 accent — one CTA per screen.
Dark sections: ink #0A0814 + Light Fields (never flat black). Poppins + Open Sans. No emoji.
```

---

## GitHub link (instead of Browse)

Paste in **GitHub or website** → **Add**:

```text
https://github.com/thejparXCD/brand-system/tree/main/design-systems/celebration-onpoint
```

If that fails, use **Browse folder** (step 2 above).

## Still stuck?

In File Explorer, go to `design-systems\celebration-onpoint` and confirm you see **`manifest.json`**.  
If not, run `git pull` again.
