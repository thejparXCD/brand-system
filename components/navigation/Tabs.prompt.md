**Tabs** — underline tab bar with gold active indicator; controlled or uncontrolled.

```jsx
<Tabs defaultValue="overview" onChange={setTab} tabs={[
  { value: 'overview', label: 'Overview' },
  { value: 'message', label: 'Message' },
  { value: 'machines', label: 'Machines' },
]} />
```

Use `tone="ink"` on dark surfaces.
